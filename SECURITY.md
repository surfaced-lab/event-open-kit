# Security policy

Event Open Kit is a public educational repository. It must never contain live credentials, private event records, personal contact information, payment details, mailbox exports, or production infrastructure configuration.

## Reporting a vulnerability

Do not open a public issue for a suspected secret or security vulnerability. Contact the repository maintainers through the private security reporting route shown on the GitHub repository. If no private route is available, contact the organization owner through a verified private channel and include only the minimum information needed to reproduce the issue.

Please do not include live credentials in a report. If a credential may have been exposed, revoke or rotate it first.

## Scope

The demo has no authentication, backend, registration, payment, email, or telemetry capability. A report about the absence of those production controls is a product limitation, not evidence that the demo is production-ready.
