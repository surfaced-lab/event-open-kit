# Changelog

All notable changes to this public learning kit are documented here.

## [0.1.0] - 2026-09-08

### Added

- A dependency-free event interface specimen with accessible interaction states.
- Synthetic event records and a documented JSON Schema contract.
- Public event marketing, sponsor proposal, and contribution playbooks.
- A repository boundary that keeps operational data, credentials, and proprietary logic private.
- A deterministic local validation command: `npm test`.

### Not included

- No real event records, customer information, attendance, transactions, email, registration, payment, API, or telemetry.
- No production-readiness claim or live deployment.
